Factions: the sides enemies belong to. Right-click this folder -> New Resource -> FactionDefinition, name it (the file name is its key, e.g. the_watch.tres is "the_watch"), then set Faction on each enemy in data/enemies/ that belongs to it.

A clue with the faction under Reveals Factions (data/clues/) makes the party know them: every member's sheet is open from the start of a fight, and the party hits them harder by Known Damage Bonus.
