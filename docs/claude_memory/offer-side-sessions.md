When I think some of the work could be sent to another (side) session, tell the user so they can choose - they asked for this on 2026-11-19 ("if you ever think again to send some tasks on the other sub session, you can let me know"), while several small bug reports were queued in the main session and two side sessions sat idle.

**Why:** they want the option of parallel work, and to be the one who decides where it runs.

**How to apply:** when bug reports or tasks pile up that are independent of what I'm doing (other files, no shared result), name which ones could go to which idle side session, in a line or as a question, before or while doing my own part. Don't hand them off without that. See [[resume-side-sessions-on-continue]].
