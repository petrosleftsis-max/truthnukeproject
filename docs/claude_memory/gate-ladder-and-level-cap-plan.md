Decided with the user on 2026-10-18, built since:
- Level cap is 64 (isopsephy of ἀλήθεια = 64), `Stats.MAX_LEVEL`. 55 (ΛΗΘΗ, Lethe/forgetting) kept in mind for the deceiving/idol side.
- Gate ladder (Stats.GATE_NAMES): World, Hermes, Pandora, Charon, Tartarus, Nemesis, Sophia, Ogdoad, Gnosis, Yaldabaoth - opening at levels 1, 8, 14, 21, 28, 34, 41, 47, 54, 61 (Stats.GATE_STEPS).
- **Moira (Fate) is central to the story, maybe more than Yaldabaoth** - never suggest Moira/Moirai, Ananke or Nyx (their mothers in myth) as an ordinary gate.
- Outside-fight gates: **Iris** (built, matches Hermes, used by Invisibility) and **Mnemosyne** (to come, matching gate 5 or 6 - undecided).
- Iris refills "like other gates" (user's words): every fight in the story; in dungeons only through rest recovery.
- The HUD's ↑ mark uses a gate name's first letter, so combat gates need distinct initials.
- The party levels at story points (Campaign.reach_level), not by experience.
- 2026-10-22: the user wants the game in five chapters, each leveling slower than the one before; I suggested chapter bands 1-18, 18-33, 33-46, 46-56, 56-64 (gains 17/15/13/10/8, each chapter opening or closing on a gate). Not chosen yet.
